# AJP-PRG8
Selection Sort
Step 1: Define a generic method selectionSort that takes an array of generic type T asinput.
Step 2: Iterate over the elements of the array from index 0 to length - 1:
Assume the current index as the minimum index (minIndex).
Iterate over the remaining elements of the array starting from the next index:
i. If the current element is smaller than the element at minIndex, update minIndex.
Step 3: Swap the element at minIndex with the element at the current index.
Step 4: Repeat steps 2 and 3 until the array is sorted.
Step 5: The array is now sorted in ascending order.
